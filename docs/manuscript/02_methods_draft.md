### Data provenance and annual compatibility

The local BRFSS source files were subject to a read-only provenance and schema audit. The CDC annual data pages report 345, 345 and 284 variables for 2023, 2024 and 2025, respectively [1–3]. The corresponding local XPT files contained 350, 301 and 283 variables. These differences remain unresolved and are reported as a source-version limitation. The respondent counts agreed with the CDC annual pages. The local 2024 file did not contain `BPHIGH6`, one of the six locked predictors, and was therefore used for compatibility assessment only. The primary model was developed using the local 2023 file and evaluated temporally using the local 2025 file. The local `_MICHD` values were checked against the CDC documented derivation rule, with no mismatches identified across the three audited annual files [4–6].
